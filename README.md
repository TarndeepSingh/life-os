# LifeOS

A personal tracker for daily tasks, habits and notes. Plain HTML, CSS and JavaScript. No build step, no server.

## Run locally
Double-click `index.html`.

## Deploy
Upload this folder to a GitHub repository (files at the repository root), then host it with GitHub Pages, Vercel or Netlify.

## Where data is stored
In each visitor's own browser (localStorage). Nothing is sent to GitHub or any server.
Data is lost if browser data is cleared. Use Settings > Export JSON to back up.
